# SEED DATA DOCUMENTATION — IDEMPOTENT DEVELOPMENT DATASET

This document provides a complete reference for the enhanced, idempotent seed script implemented in `Backend/src/database/seed/seed.ts`.

---

## 1. EXECUTION

To execute the seed script against the local MongoDB replica set (`mongodb://localhost:27018/ielts-lms?replicaSet=rs0`):

```bash
npm --prefix Backend run seed
```

### Idempotency Guarantee:
The script uses deterministic entity IDs (e.g. `user-admin-1`, `course-ielts-75-a`, `les-2026-11-15-a`), unique indexes, and upsert logic (`findOneAndUpdate` with `upsert: true` or duplicate-key catching).  
Running the seed script multiple consecutive times preserves the exact same database counts without generating duplicate records.
